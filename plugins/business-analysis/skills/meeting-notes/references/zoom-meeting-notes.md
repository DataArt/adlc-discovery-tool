# Zoom meeting notes

Use this procedure for hourly Outlook calendar checks and manual requests for notes from Zoom recordings. It specifies the evidence, draft format and Outlook handoff for this workflow. Use the [publication procedure](meeting-job.md) for revision-specific approval, Confluence checks and recovery from uncertain writes.

## Set up the project and sources

Confirm the BA or PM reviewer, Outlook calendar and sender mailbox, event filter, timezone, private review chat, Zoom access, and Confluence site, space and parent. Record the approved project names, business purpose, scope and terminology in the workspace configuration for the job. Use the supplied context to interpret terms and confirm current project details with the reviewer.

Check whether the scheduled identity can retrieve the correct Zoom occurrence and inspect its audio and transcript. Check separately whether the interactive host can publish to the selected Confluence parent and save an Outlook reply draft linked to the original invitation. Report unavailable capabilities before scheduling.

## Collect and verify evidence

- Every hour, apply the configured event filter. An occurrence first qualifies when its end time plus 15 minutes falls at or before the check. Cover the interval since the last successful check, including meetings still awaiting assets. Reconcile occurrence IDs against existing drafts, reviews and published notes before starting another draft. If prior state cannot be determined, resolve the possible duplicate with the reviewer.
- Use the invitation's Zoom details and occurrence time to match the recording and transcript. Flag missing or ambiguous links to the reviewer. Verify the call has ended. Listen to the recording and correct only words, figures or speakers supported by the audio. A recording URL alone does not establish that audio was checked.
- For calendar access failures, unavailable meetings or pending Zoom assets, use up to three retries at 15, 30 and 45 minutes when the host supports retry scheduling. Report the missing capability or exhausted retries in the review chat. For partial material, identify the gap and wait for the reviewer's direction before drafting.
- For a manual request, start from the supplied link, recording or transcript. An Outlook event is optional. Transcribe a recording when supported. With only a transcript, ask whether to proceed using it as supplied. Disclose the evidence actually used.

## Prepare one draft for the occurrence

Write in business English and preserve official names and identifiers. Include the original or confirmed meeting title, invitation list, confirmed actual attendees, date, start time, timezone, notes author and audience-shareable sources. List meeting files with their links when available. Distinguish invitation from attendance.

Group **Topics Discussed** by topic, identifying the project where useful. Follow with **Decisions made** and their conditions, **Open questions**, and **Follow-ups/Action points** with agreed next steps, owners and deadlines. Preserve relative deadlines as stated. Use “Not specified” for missing fields and “None recorded” for empty sections. Keep all projects discussed in the same set of notes.

Below the proposed page body, show **Uncertainties to clarify** in a separate private reviewer block. Ask specific questions about disputed wording, missing commitments or gaps in the recording. Apply confirmed answers to the draft and present the revised version. If uncertainty remains, ask whether the reviewer wants to finalize with those points unresolved. Keep unconfirmed outcomes out of decisions.

## Publish, then prepare the reply

Show the BA or PM the exact revision, page title (`YYYY-MM-DD - Meeting title`), destination and proposed follow-up. On explicit approval in chat, publish only the approved notes and verify the page. Keep reviewer questions and private discussion out of both outputs.

After verified publication, save a reply draft on the original Outlook invitation, addressed to its original invitees. Preserve the reply subject. Insert a brief greeting, thanks and the approved notes above the existing thread. Prefer HTML with headings, links and tables. If only plain text is supported, preserve readable sections and tell the reviewer. The BA or PM sends the email.

Return the Confluence link and the Outlook draft status or link. Report confirmed differences between invitees and attendees in chat. For a manual call without an invitation, finish with the page link. If a linked reply draft is unsupported or its save is uncertain, report that outcome and check for an existing draft before retrying. Resume at the unfinished handoff when the page is already verified.
