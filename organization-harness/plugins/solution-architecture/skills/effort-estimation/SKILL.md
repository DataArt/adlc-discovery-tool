# Effort Estimation

## Operating principles

Read [operating principles](references/operating-principles.md) before executing. This skill is a starter draft, not an approved organizational policy.

## Required context

Scope, delivery assumptions, team capabilities and historical data if available.

## Workflow

1. Decompose scope into deliverables and activities.
2. Identify dependencies, uncertainty and non-functional work.
3. Estimate ranges with explicit units and rationale; avoid false precision.
4. Summarize assumptions, exclusions, risks and sensitivity to scope changes.

## Expected output

Work breakdown, effort ranges, assumptions and exclusions.

## Quality gate

Label estimates as provisional; do not present them as commitments.
