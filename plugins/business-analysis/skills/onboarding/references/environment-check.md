# Check workflow readiness

Identify the requested workflow, host and target scope. Use the following prerequisites:

| Workflow                   | Evidence needed                                                                                                                                                                                                                                                                                                                        |
| -------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Meeting notes              | Readable notes or transcript for the intended meeting. Meeting or calendar metadata alone establishes only that the event is accessible.                                                                                                                                                                                               |
| Requirements analysis      | Requirements and stakeholder objectives, supplied directly or retrieved from the selected sources. Identify missing objectives before assessing alignment.                                                                                                                                                                             |
| Story generation           | A supplied requirements baseline, or access to the selected baseline and any requested Jira backlog context.                                                                                                                                                                                                                           |
| Weekly requirements review | The scope, reporting window, destination, skill and access to both Jira and Confluence through Atlassian in the [job definition](../../../jobs/weekly-requirements-review.json). Recurring execution also needs a scheduler with access under the intended identity.                                                                   |
| Daily meeting notes        | Verify scoped Outlook Calendar and Teams search, readable meeting evidence and private review delivery under the scheduler identity. Check optional Zoom access if selected. Verify interactive access to the intended Confluence parent separately. Report write capability as unverified where the host cannot inspect it read-only. |
| Hourly Zoom meeting notes  | Verify filtered Outlook calendar access and actual Zoom recording and transcript access for the same occurrence. Check private review delivery, Confluence destination and Outlook linked reply-draft capability under the appropriate identities.                                                                                     |
| Specialist review          | The selected role available in the host for delegated execution. For local installation, check support and the intended project scope.                                                                                                                                                                                                 |

For a full environment check, also inspect every required app in the [manifest](../../../.app.json). Use the scoped read probes in the [connection guide](connections.md). Report missing access and its next action. Keep this check read-only. Distinguish missing tools, expired sign-in, denied access and unverified scope.

For each workflow report ready, limited or blocked, with evidence and one next action. Identify manual inputs that would unblock drafting. Report interactive and scheduled access separately when only one has been tested.
