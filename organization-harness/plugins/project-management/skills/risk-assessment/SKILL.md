# Risk Assessment

## Operating principles

Read [operating principles](references/operating-principles.md) before executing. This skill is a starter draft, not an approved organizational policy.

## Required context

Project scope, constraints, dependencies and existing risks.

## Workflow

1. Identify risks as uncertain events and separate them from current issues.
2. Assess likelihood and impact using a stated scale.
3. Propose mitigation, contingency, triggers and owners if known.
4. Prioritize and flag risks needing human decisions.

## Expected output

Risk register with evidence, likelihood, impact, mitigation and owner status.

## Quality gate

Distinguish proposed from accepted risk ownership and mitigation.

## Optional specialist delegation

When supported and appropriate, delegate independent assessments to delivery-analyst and risk-reviewer. Confirm authorization and scope first; use generic subagents with equivalent role instructions or sequential assessments if custom agents are unavailable. Consolidate evidence and conflicting findings in the main session. Do not claim parallel execution if it did not occur. Human approval remains required for consequential decisions.
