# Status Report

## Operating principles

Read [operating principles](references/operating-principles.md) before executing. This skill is a starter draft, not an approved organizational policy.

## Required context

Reporting period, objectives, available delivery evidence and prior status if provided.

## Workflow

1. Establish reporting period and evidence sources.
2. Summarize progress against milestones and identify variance.
3. Capture blockers, risks and decisions needed with responsible parties when known.
4. Present concise status and next-period priorities.

## Expected output

Status summary, progress, blockers, risks and next steps.

## Quality gate

Do not invent metrics or infer completion from missing evidence.
