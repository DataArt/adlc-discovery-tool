Which layer feeds which phase

Business and Technical Context are company-level inputs; every phase consumes, none contributes back. Operational Context is the live sprint layer. Project Context, owned by the harness, is what Implementation writes to.

Every row is a wiring requirement, not a suggestion. If a phase can't reach the layer it needs, the loop breaks there and the AI defaults back to generic patterns.
