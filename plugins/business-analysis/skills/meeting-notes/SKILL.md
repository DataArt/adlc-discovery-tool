# Meeting Notes

## Operating principles

Read [operating principles](references/operating-principles.md) before executing. This skill is a starter draft, not an approved organizational policy.

For requests to verify a transcript against Zoom audio and for the hourly calendar job, follow the [Zoom meeting procedure](references/zoom-meeting-notes.md), including its draft format and approved Outlook handoff. For other meetings, use the workflow below.

For a scheduled discovery run or a request to review, revise or publish a job draft, follow the [discovery and publication procedure](references/meeting-job.md). For supplied notes, start with the workflow below.

For `Start setup` in a Meeting Notes context, follow the [Zoom setup procedure](references/zoom-meeting-notes.md#set-up-the-project-and-sources).

## Required context

Transcript or notes; meeting purpose; participant names when known.

## Workflow

1. Identify the purpose and separate facts from proposals.
2. Extract decisions, actions, owners and due dates; mark missing values according to the selected draft format.
3. Capture unresolved questions and dependencies; preserve source anchors where available.
4. Present the draft for human review before any external publication.

## Result

Apply the [meeting-notes result contract](references/result-contract.md) to each draft before handing it to the reviewer.
