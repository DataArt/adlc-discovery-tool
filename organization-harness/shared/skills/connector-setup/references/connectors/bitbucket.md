# Bitbucket setup guide

1. Discover whether the host exposes Atlassian plugin or approved MCP integration. If not, consult the workspace administrator; do not invent an endpoint or installation method.
2. In the host's Plugins/settings or approved MCP configuration UI, select the approved integration and complete its authorization flow. Never paste credentials into chat.
3. Confirm the organization/account and intended resource with the user. Request only required access.
4. Verify: Read one explicitly selected repository or pull request. Report the resource and outcome, avoiding unnecessary content in the report.
5. If unavailable, ask for a sanitized manual export when appropriate. Mark live access as unverified.

These steps are provider-neutral; exact UI, plan, scopes and authentication depend on the approved integration and host version.
