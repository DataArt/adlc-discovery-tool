# Pattern: Task tracking

For a full-chain run, track the seven units from the root banner. For direct entry,
track only the requested unit; an Investigate session may add its selected child
units in evidence-chain order. Do not pre-create a fixed number of workshops.

Use exposed TaskList/TaskCreate/TaskUpdate tools if available, reusing this
engagement's existing tasks. Otherwise use TodoWrite if available; without native
tracking, use the standing phase page. Never require unavailable tools.

Mark work active before starting and complete only after inspecting its artifacts
and required confirmation/review evidence. Gate closure requires an actual recorded
stakeholder outcome; a stub handoff stays pending. Reconcile task state against
`docs/AI SDLC/01 Engagement/04 Where We Are/` on resume, reopen invalidated units,
and keep downstream work pending until prerequisites hold. These pages, not native
tasks, are the durable authority; record blockers and next actions there.
