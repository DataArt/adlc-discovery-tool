# Pattern: Artifact confirmation

Draft the requested artifact or coherent set of related changes, then present the
files and the material findings or interpretations for engagement-lead review.
Obtain confirmation before treating the draft as validated evidence for downstream
work. Existing explicit confirmation covers unchanged material; ask about new or
materially changed interpretations rather than repeating approval prompts per file.

Apply corrections and re-present what changed. Where required, satellite review
follows this confirmation and checks evidence integrity. If that review changes the
meaning, obtain confirmation of the revised interpretation before reporting it as
validated. Mechanical citation repairs do not require another content sign-off.

Content confirmation, evidence review, stakeholder gate approval, and permission to
commit are distinct. None substitutes for another; use the decision already supplied
when it actually covers the action at hand.
