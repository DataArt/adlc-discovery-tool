# Business Analysis

Discovery, requirements and backlog preparation.

## Skills

- `meeting-notes` – Turn meeting transcripts or notes into accurate decisions, actions and open questions. Use after a meeting or when asked to summarize a discussion.
- `requirements-analysis` – Analyze requirements for scope, ambiguity, gaps, constraints and traceability. Use for discovery and requirement refinement.
- `story-generation` – Draft implementation-ready user stories and acceptance criteria from requirements. Use for backlog preparation or refinement.

All skills are starter drafts; validate with representative scenarios before adoption.

## Setup and recurring jobs (v0.2.0)

Use the plugin setup action or invoke `onboarding`. `build.config.json` defines default connector requirements; `agents/` and `jobs/` contain draft specialist and recurring job definitions. These are not automatically registered. See the bundled setup skills. Generated shared skill copies must be refreshed with `tooling/manage.py sync` from the monorepo.
