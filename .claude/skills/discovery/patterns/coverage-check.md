# Pattern: Coverage Check

Used by Investigate and Gate 1 to assess readiness from actual evidence. Solution and Roadmap have separate prerequisites in the gate reference.

## Investigate coverage — both must hold

1. **Every SDLC Domain page has moved past its placeholder.** Read the Problems table in `01 Engagement/04 Where We Are/02 Investigate.md` — every row must be past `⏳ Not diagnosed` with a real, workshop-evidenced working hypothesis, not a template placeholder.
2. **Strategic Intent holds steady across a validation session.** The most recent Capture pass didn't surface anything that reorders or cuts an item in `04 Goals/02 Strategic Intent.md`. If it did, Intent isn't final yet — reference `01 Engagement/03 Process/04 Evidence Chain.md`, which treats a re-derivation as the one thing Strategic Intent should never need (it's only ever validated or grounded).

Per `01 Engagement/05 Workflows/03 Investigate/00 Orchestration.md`, this is what unblocks Gate Review — not a fixed number of workshops or a calendar date.

## Result

Return whether both conditions hold, with the specific evidence or gaps. Coverage
clear means eligible for Gate 1, not approved by Gate 1. A later gate may invalidate
this assessment; record affected items for revalidation. The caller decides the
next action within the requested scope and announces it.
