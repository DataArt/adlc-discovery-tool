# Patch 0029 — process-collaboration-restructure

## Summary

Groups the three people/tooling-facing pages under `docs/AI SDLC/01 Process/` into their own `09 Contribution/` subfolder, following the same subfolder convention already used by `06 Where We Are/`, `07 Workflows/`, and `08 Reference/` (numbered `01`, `02`, … internally rather than carrying their old top-level numbers):

- `05 Team Collaboration.md` → `09 Contribution/01 Team Collaboration.md`
- `09 Claude Desktop Setup.md` → `09 Contribution/02 Claude Desktop Setup.md`
- `10 Branching Policy.md` → `09 Contribution/03 Branching Policy.md`

(The subfolder was briefly named `09 Collaboration` before landing as `09 Contribution` — the individual page `01 Team Collaboration.md` keeps its own title/filename, since that names the page's specific topic, not the grouping folder.)

This leaves `01 Process/` with only its four static process-definition pages at the top level (`01 Overview`, `02 Terminology`, `03 How the Engagement Runs`, `04 Evidence Chain`) plus its four subfolders (`06 Where We Are`, `07 Workflows`, `08 Reference`, `09 Contribution`). The sidebar is auto-generated by `apps/docs-web/.vitepress/utils/sidebar.ts`'s `scanSection` (files sorted and listed before directories, both alphabetically within their group), so no `config.ts` changes were needed — `09 Contribution` naturally sorts after `08 Reference` among the directory entries.

Cross-references updated to match:

- The three moved files' own internal links to each other (now same-folder, renumbered) and to now-one-level-up pages (`../04 Evidence Chain.md`, `../07 Workflows/01 Initiation.md`, `../03 How the Engagement Runs.md`) — relative paths, not absolute, so the folder depth change had to be accounted for.
- `docs/AI SDLC/01 Process/index.md`'s directory table: three rows removed from their old positions, three new rows added under a "Contribution —" prefix pointing at the new subfolder paths.
- Three `.claude/skills/` files that name-checked `05 Team Collaboration.md` or `09 Claude Desktop Setup.md` in prose (not as clickable links, but as file-identifying references that would otherwise mislead a reader searching for them): `bootstrap-client/SKILL.md`, `discovery-investigate-capture-current-state/SKILL.md`, `discovery/pattern-do-report-commit.md`.

Verified with `yarn nx run site:build` — VitePress has no `ignoreDeadLinks` configured, so a broken relative link would fail the build; it completed clean.

**Not included**: no changes to `06 Where We Are/`, `07 Workflows/`, or `08 Reference/` content or numbering — only the new `09 Contribution/` subfolder and the cross-references listed above.
