# Story Generation

## Operating principles

Read [operating principles](references/operating-principles.md) before executing. This skill is a starter draft, not an approved organizational policy.

## Required context

Requirements baseline, personas, constraints and existing backlog if available.

## Workflow

1. Map stories to requirements and split by user outcome.
2. Draft story intent, acceptance criteria and relevant non-functional constraints.
3. Identify dependencies and open questions; flag unresolved scope.
4. Present candidate stories for review; do not publish automatically.

## Expected output

Story drafts with acceptance criteria, traceability and dependencies.

## Quality gate

Acceptance criteria must be testable; do not silently add scope.
