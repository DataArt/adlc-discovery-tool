# 🚩 Milestones

> What is the first measurable step, and who owns it?

Milestones are not a project plan — they are the minimum set of commitments that prevent the engagement from ending as a set of interesting insights with no accountable next action. Each milestone answers three questions: **what** will exist or be true, **who** is accountable, and **by when**.
