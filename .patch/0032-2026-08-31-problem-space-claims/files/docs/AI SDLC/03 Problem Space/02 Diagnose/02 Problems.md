## Reading the Registry

Every problem gets an ID the day it's first named, and keeps it for the life of the engagement — IDs are never reused, so a reference in a workshop note or a meeting minute from two months ago still resolves. Status only moves forward; a problem that turns out to be wrong is marked **Retracted** with the reason kept, not deleted.

| Status       | Meaning                                                                |
| ------------ | ---------------------------------------------------------------------- |
| 🟡 Reported  | Raised by a single source — one stakeholder, one document, one session |
| 🟢 Confirmed | Corroborated by a second, independent source                           |
| 🔵 Measured  | Quantified — a number backs the impact claim, not just a description   |
| ⚫ Retracted | Removed from the diagnosis; reason kept for the record, ID not reused  |

A problem can sit at 🟡 Reported through publication. That marks it as a lead, not yet a basis for pilot planning. Few problems reach 🔵 Measured in a discovery-scale engagement.
