# Business Analysis

Discovery, requirements and backlog preparation.

Start [onboarding](skills/onboarding/SKILL.md) for the guided flow through connections, specialist agents, meeting-notes and requirements-review jobs, and a final environment check. You can return to any step directly. For example, ask “Recheck Jira for this project” or “Run the environment check again.” Notes and requirements supplied directly in chat can be used immediately.
