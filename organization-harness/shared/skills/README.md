# Shared skills (canonical source)

Edit shared skills here, never in generated plugin copies. Run `python3 tooling/manage.py sync` after changes to shared skills, standards, agent definitions, jobs or plugin build configuration. Generated copies under each plugin's `skills/` are checked in to support Git marketplaces without a build step on installation. Shared templates use generated per-plugin `references/plugin-config.json`; they are not standalone installable skills as authored here.
