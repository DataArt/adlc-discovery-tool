# Technology Selection

## Operating principles

Read [operating principles](references/operating-principles.md) before executing. This skill is a starter draft, not an approved organizational policy.

## Required context

Decision scope, candidate technologies, evaluation criteria and constraints.

## Workflow

1. Define decision criteria and agree or label provisional weights.
2. Gather evidence for each option and identify unknowns.
3. Compare trade-offs and operational implications.
4. Recommend an option conditionally; document decision and validation plan.

## Expected output

Decision matrix, rationale, trade-offs and validation actions.

## Quality gate

Verify time-sensitive claims when possible; disclose unverified evidence.
